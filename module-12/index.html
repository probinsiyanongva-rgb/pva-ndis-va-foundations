Decision layer

  • OK — the required checks are satisfied and the task can proceed within role.
  • FLAG — an exception needs attention or verification through the normal owner/workflow.
  • ASK — a factual clarification or approved workflow is needed before proceeding.
  • ESCALATE — the matter requires authority or urgent action beyond the VA role, including a privacy or security incident.

Important current-information note

This module teaches safe administrative behavior rather than privacy-law certification. Real provider work must follow the provider's current privacy, security, records and incident procedures.

The OAIC's current APP guidance identifies APP 8 as covering cross-border disclosure of personal information and APP 11 as covering reasonable security steps for personal information. The OAIC also explains that identity/authority should be verified before providing access to personal information under APP 12. These sources should be rechecked before course release or reuse after a material change.

Module 12 — Prove It Summary

Your final Module 12 evidence should demonstrate:

MINIMIZE → PROTECT → VERIFY AUTHORITY → STOP UNSAFE HANDLING → ESCALATE/ASK → FOLLOW UP → CLOSE

Required evidence

  • Data-handling checklist
  • Privacy-incident response
  • Records/authority request handling
  • Security_Extensions practice
  • Follow-up/closure evidence where applicable

Final self-check

Before marking Module 12 complete, ask:

  • Did I use only the information needed for the task?
  • Did I keep fictional training data separate from real work?
  • Did I use an approved system/location?
  • Did I verify authority before disclosure?
  • Did I stop unsafe AI, storage or credential workarounds?
  • Did I choose ASK vs ESCALATE based on the actual situation?
  • Did I identify the correct owner?
  • Did I record a follow-up trigger?
  • Did I define what would prove closure?
  • Did I stay within the VA role?
