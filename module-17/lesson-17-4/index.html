Lesson 17.4 — Your First 30 Days

Practice file: Wattlebird Sandbox Pack v2.3.4 — fictional training data. Work from a copy.Open the Wattlebird practice file

1. Progress Reminder

Your first month is a period of learning the provider, learning the systems, performing routine work and building reliability.

← Module 17 overview

2. Why This Matters

A written plan gives you a practical way to track what you need to learn, what you can already perform and where you need clarification.

3. Learn

Use four stages:

Days 1–7 — Learn the Provider

Understand:

  • services and workflows;
  • team roles;
  • communication channels;
  • working hours;
  • escalation contacts;
  • key procedures.

Days 8–14 — Learn the Systems

Confirm:

  • account/access process;
  • SOP locations;
  • record systems;
  • task and follow-up process;
  • privacy/security expectations;
  • current-source expectations where relevant.

Days 15–21 — Perform Routine Work

Work on assigned tasks with appropriate review.

Track:

  • questions;
  • corrections;
  • recurring tasks;
  • follow-ups;
  • areas where you need more practice.

Days 22–30 — Improve Reliability

Look for:

  • repeated questions;
  • preventable errors;
  • workflow gaps;
  • useful SOP improvements;
  • communication improvements.

Discuss improvement ideas with the appropriate manager rather than changing controlled workflows without authorization.

4. See It

A useful first-30-days question set includes:

Access

What systems and folders should I have access to, and who approves access changes?

SOPs

Where is the current version of each SOP?

Escalation

Who should I contact for urgent, privacy, incident, scheduling and billing issues?

Privacy and security

What provider-specific rules apply to participant information, storage and approved tools?

Communication

Which channel should I use for routine work, urgent work and handovers?

Review

How will my work be reviewed during the first month?

8. Work Boundary

Your first month is a learning period.

Ask for the provider's current procedure when something is unclear. Follow assigned permissions and escalation paths. Do not promise instant independence or make decisions outside your role simply to appear confident.
