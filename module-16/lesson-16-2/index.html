Lesson 16.2 — Labeling and Honest Representation

Practice file: Wattlebird Sandbox Pack v2.3.4 — fictional training data. Work from a copy.Open the Wattlebird practice file

1. Progress Reminder

A polished portfolio still needs accurate labels. The person reviewing it should understand what was practiced and what was real.

← Module 16 overview

2. Why This Matters

Practice can demonstrate useful skills. Clear labeling protects the credibility of your portfolio and prevents a training simulation from being presented as client experience.

3. Learn

Use the course artifact label:

FICTIONAL TRAINING ARTIFACT — CREATED FOR PRACTICE PURPOSES ONLY
NO REAL NDIS PARTICIPANT DATA USED

Distinguish clearly between:

Training experience

What you learned through the course.

Practice artifacts

Documents, spreadsheets, records and workflows completed in the fictional Wattlebird environment.

Actual client experience

Work performed for a real client or employer.

These categories should not be blended.

The portfolio must also avoid implying:

  • real NDIS participant experience;
  • official NDIS certification;
  • employment by Wattlebird;
  • real client work for Wattlebird.

4. See It

Risky wording

“Managed participant invoices for Wattlebird Support Services.”

This can sound like real client employment.

Training-based wording

“Completed fictional NDIS invoice-administration exercises using a simulated provider environment.”

This tells the reviewer what was actually practiced.

5. Try It

Choose five artifacts from your portfolio.

For each one, check:

  • Does the artifact say it is fictional training work?
  • Does the description accurately state what you practiced?
  • Does any wording imply a real participant?
  • Does any wording imply Wattlebird was a real employer/client?
  • Does any claim about your skill have evidence behind it?

Revise anything that could mislead a reviewer.

Use the existing M1_Profile_Template rather than creating an unrelated second professional identity.

Work it here or in your own file. Saved in this browser only as you type.

6. Check Yourself + Model Answer

Question: What should a reviewer be able to understand from your artifact label?

Model answer: That the artifact was created for practice, that the participant/provider information is fictional, and that it demonstrates a training exercise rather than real client work.

Write your own answer first, then compare. Saved in this browser only.

7. Prove It

Complete your five-artifact labeling audit.

Retain the corrected descriptions as portfolio evidence.

Draft or track your Prove It evidence here. Saved in this browser only — save the finished evidence in your own file with the name the lesson gives you.

8. Work Boundary

Honest representation applies to the whole application:

  • profile;
  • portfolio;
  • cover letter;
  • outreach;
  • interview answers.

Training evidence can support a skills claim. It should not be presented as paid client experience.
