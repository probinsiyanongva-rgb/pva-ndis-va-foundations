2. Why This Matters

A task description is often only the starting point. Good administrative work connects the request to the relevant record, checks the evidence and records what was actually found.

3. Learn

Use this sequence for each task:

Open the source → Locate the record → Verify identity → Check relevant fields → Record evidence → Classify → Take the authorized action

Use the source appropriate to the task.

Examples of source paths include:

  • roster issue → M15_Capstone_Roster / Staff
  • invoice issue → M15_Capstone_Invoice_Batch + M15_Capstone_Invoice_Evidence
  • participant or plan context → Participants / relevant plan record
  • privacy event → Inbox / security-related record
  • incident → Inbox / Incident_Log / capstone-specific evidence where named
  • current-information question → the appropriate official source

For current-source tasks, record the official source you actually checked.

4. See It

Consider a generic example:

An invoice appears unusual.

The task description alone does not prove that it is wrong.

The administrative path is:

Open invoice → identify participant → check service/date/item/quantity/rate/context → check delivery evidence where required → document finding → classify → route if necessary.

That creates traceable evidence.

The same principle applies to roster, privacy, onboarding, incident and funding-related tasks.

5. Try It

Work through the capstone tasks using the actual Wattlebird records.

For each task, record:

  • What I found
  • Evidence/source
  • Classification
  • Action
  • Owner/handoff
  • Reason

Where information is missing, record the question rather than inventing an answer.

Where authority is required, record the handoff.

Work it here or in your own file. Saved in this browser only as you type.

6. Check Yourself + Model Answer

Question: What makes a capstone action traceable?

Model answer: The action can be connected to a source record or clearly documented assumption, the finding is recorded, the classification is stated, and the next owner/action is identifiable.

Write your own answer first, then compare. Saved in this browser only.

7. Prove It

Complete the execution and classification fields for the capstone.

Your evidence should demonstrate that you checked the underlying records instead of guessing from the incoming message.

For current-information tasks, retain the source and date checked.

Draft or track your Prove It evidence here. Saved in this browser only — save the finished evidence in your own file with the name the lesson gives you.

8. Work Boundary

The capstone evaluates administrative judgment.

The VA:

  • records facts;
  • checks available evidence;
  • asks when clarification is required;
  • flags exceptions;
  • escalates decisions requiring authority;
  • follows provider procedure;
  • tracks the result.

The VA does not independently decide matters outside the role.
