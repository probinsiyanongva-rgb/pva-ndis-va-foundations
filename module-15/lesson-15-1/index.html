You have practiced the individual workflows. The capstone now places several types of work into one simulated workweek.

2. Why This Matters

A VA's workday can contain several competing requests. The skill being tested here is not simply knowing the correct label. You must decide what requires attention, identify dependencies, use the right source, and keep work moving.

3. Learn

Open the Wattlebird workbook and the M15_Capstone sheet. The assessment scenario details are in M15_Capstone_Scenarios. CAP-01/02 use M15_Capstone_Roster; CAP-01 also uses the neutral CAP-01 cover-candidate extract in that sheet; CAP-05 uses M15_Capstone_Invoice_Batch plus M15_Capstone_Invoice_Evidence; CAP-10 uses M15_Capstone_Audit_Records.

The capstone contains ten mixed-workweek tasks:

  • CAP-01 — same-day shift-cover problem using the capstone roster evidence
  • CAP-02 — W10 overlap in the supplied draft roster
  • CAP-03 — funding question from a new referral
  • CAP-04 — Melbourne public-holiday check for P12
  • CAP-05 — fresh six-line invoice mini-batch
  • CAP-06 — new wrong-recipient privacy incident
  • CAP-07 — P04 service-agreement review draft
  • CAP-08 — P10 future support-coordination funding/booking question
  • CAP-09 — new P02 after-hours incident
  • CAP-10 — audit-preparation gap check

These combine several kinds of work and use M15 assessment inputs created for this module rather than copying the worked scenarios from earlier modules. Some require immediate attention. Some depend on an authorized person's decision. Some require current-source verification. Some can proceed as routine administrative work.

4. See It

Before solving anything, inspect the work queue.

For each task, ask:

  1. What happened?
  2. What source record should I open?
  3. Is there a timing or safety/privacy dependency?
  4. Who has authority for the next decision?
  5. What evidence will prove completion?

This first pass is your work queue, not your final answer.

5. Try It

Open:

  • M15_Capstone
  • M15_Capstone_Scenarios
  • M15_Capstone_Invoice_Batch + M15_Capstone_Invoice_Evidence for CAP-05
  • M15_Capstone_Roster for CAP-01 (including its neutral cover-candidate section); M15_Capstone_Roster / Staff for CAP-02
  • Participants / a copied M10_Agreement template for CAP-07; Participants only for CAP-08
  • Follow_Up_Log for follow-up evidence
  • the official source named by a task when a current-information check is required

Build your first-pass priority order.

Record your reasoning in your own task notes.

Work it here or in your own file. Saved in this browser only as you type.

6. Check Yourself + Model Answer

Question: What should you identify before deciding what to work on first?

Model answer: Identify urgency, safety/privacy/compliance implications, dependencies, affected people, required source checks, and whether an authorized owner must make the decision.

There is no value in treating every task as equally urgent.

Write your own answer first, then compare. Saved in this browser only.

7. Prove It

Complete your first-pass work queue.

For every capstone task, enter your own:

  • priority;
  • initial classification;
  • source record to check;
  • reason.

Do not solve the entire capstone from the task description alone.

Draft or track your Prove It evidence here. Saved in this browser only — save the finished evidence in your own file with the name the lesson gives you.

8. Work Boundary

The capstone does not give you authority to make provider, clinical, legal, funding, approval or reportability decisions.

When the task requires an authorized decision, your evidence should show the handoff and follow-up.

9. Next Step

Now work the records behind the tasks. Your next stage is to check evidence before taking action.
