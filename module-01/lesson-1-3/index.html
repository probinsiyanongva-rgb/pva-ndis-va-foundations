The next skill is simple but powerful:

Check first. Act second.

← Module 1 overview

2. Why This Matters

Many administrative mistakes happen because someone starts editing before confirming the basic facts.

A reliable VA pauses long enough to identify:

  1. the record;
  2. the person;
  3. the date / time;
  4. the source;
  5. the requested action;
  6. the authority or owner.

This creates a repeatable process.

3. Learn

Use this six-point check before changing an administrative record:

1. Record
What exact record are you working on?

2. Identity
Who or what does the record belong to?

3. Date / Time
What date or time applies?

4. Source
Where did the information come from?

5. Requested Action
What exactly has someone asked you to do?

6. Authority / Owner
Are you authorized to complete the action, or does someone else need to decide?

If one of these is unclear, pause and classify the issue.

4. See It — Wattlebird Example

Suppose an inbox message says:

“Please update the roster for tomorrow.”

That message is not yet enough information to safely edit a roster.

Before acting, the VA would identify:

  • which participant;
  • which staff member;
  • which shift;
  • which date;
  • what change is requested;
  • whether the sender is authorized to request the change;
  • whether the requested change creates a conflict.

The message may be clear enough to act on—or it may need an ASK.

6. Check Yourself + Model Answer

Write your own answer first, then compare. Saved in this browser only.

Model answer

A strong answer identifies the actual record and requested action before deciding what to do.

For a message where the requested change is clear, the relevant record exists, and the sender is authorized, OK may be appropriate.

If a factual detail is missing, use ASK.

If the request conflicts with another record or requires review, use FLAG.

If the matter involves authority beyond your role, or an urgent safety, privacy, or compliance concern, use ESCALATE.

The classification depends on the evidence in the record—not on how urgent or convenient the request feels.

8. Work Boundary

A VA should not treat every request as an instruction that must be executed immediately.

A request can be:

  • incomplete;
  • unclear;
  • outside your authority;
  • inconsistent with another record;
  • sensitive;
  • urgent.

Your responsibility is to recognize which situation you are facing and move it through the correct workflow.
