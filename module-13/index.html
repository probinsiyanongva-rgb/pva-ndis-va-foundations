Your core workflow

RECOGNIZE → RECORD → ESCALATE → FOLLOW PROVIDER PROCEDURE → FOLLOW UP → CLOSE

Decision layer

  • OK — the required checks are satisfied and the task can proceed within role.
  • FLAG — an exception needs attention or verification through the normal owner/workflow.
  • ASK — a factual clarification or approved workflow is needed before proceeding.
  • ESCALATE — the matter requires authority or urgent action beyond the VA role, including safety, privacy, complaints requiring urgent attention, or urgent incidents.

Final self-check

Before completing Module 13, ask:

  • Did I record facts rather than assumptions?
  • Did I recognize urgent situations promptly?
  • Did I use the correct Wattlebird urgent channel?
  • Did I start the backup clock from the handoff time?
  • Did I keep the event time separate from the received time?
  • Did I record complaints neutrally?
  • Did I route screening issues to the authorized owner?
  • Did I avoid deciding legal/reportable status?
  • Did I avoid inventing missing audit evidence?
  • Did I record owner, next action, follow-up and closure?
