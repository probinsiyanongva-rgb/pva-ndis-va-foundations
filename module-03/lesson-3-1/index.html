Lesson 3.1 — Your Basic Remote-Work Workspace

Practice file: Wattlebird Sandbox Pack v2.3.4 — fictional training data. Work from a copy.Open the Wattlebird practice file

1. Progress Reminder

A VA needs a workspace where another person can understand where work belongs.

For this course, you will practise with a simple folder structure and fictional files.

The goal is easy retrieval:

Open → find → understand → use → save → find again

← Module 3 overview

2. Why This Matters

A messy workspace creates friction.

A file may exist but still be difficult to use if:

  • nobody knows where it belongs;
  • the filename is unclear;
  • the latest version is difficult to identify;
  • fictional practice work is mixed with real information;
  • another person cannot find the evidence.

Good organization supports handover and reduces avoidable mistakes.

3. Learn

The course portfolio structure uses six broad folders:

  1. 01_Workplace_Foundations
  2. 02_NDIS_Admin
  3. 03_Operations
  4. 04_Privacy_Compliance
  5. 05_Capstone
  6. 06_Job_Readiness

Wattlebird's M16_Portfolio sheet shows what belongs in each folder.

For Module 3, you are organizing training evidence.

Keep the boundary clear:

Fictional training data may be handled in the course practice environment. Real participant information belongs only in provider-authorized systems, accounts, storage, permissions, and workflows.

8. Work Boundary

Personal storage is acceptable for fictional course evidence when you are completing the training exercise.

Real participant information is different.

A provider's actual requirements may specify:

  • approved storage;
  • approved accounts;
  • permissions;
  • access controls;
  • naming conventions;
  • retention procedures.

Follow the provider's authorized workflow for real work.
