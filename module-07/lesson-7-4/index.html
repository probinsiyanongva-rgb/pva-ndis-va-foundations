2. Why This Matters

A role map should help you answer:

“Who owns this, and what should I do next?”

It should also help you avoid repeated uncertainty.

3. Learn

A useful working role map can contain:

Field Purpose
RoleWho performs the function
Typical task/questionWhat usually belongs there
Owner/contactWho you route to
Backup/contactAlternative route if documented
ChannelApproved communication method
Escalation routeWhere urgent/authority matters go
NotesProvider-specific instructions
Last checkedHelps keep the map current

Use the Wattlebird provider information as your source.

Do not create personal contact details or procedures that are not in the training environment.

4. See It — Wattlebird Example

After working through the tickets, you might update a row from:

Provider Operations — roster

to something more useful:

Provider Operations — roster administration
Owner: documented Wattlebird operations contact
Typical work: roster checks, availability, shift exceptions
Escalation: authorised operations decision-maker
Follow-up: record outstanding action and check by agreed trigger

The point is to make the map operational without turning it into an invented directory.

5. Try It

  1. What did the ticket teach you?
  2. Which role owns the work?
  3. What does the VA do before handing it over?
  4. What is the follow-up trigger?
  5. What indicates closure?

6. Check Yourself + Model Answer

Question: Should a role map replace provider procedures?

Model answer: No. It is a working aid. Provider procedures and authorised instructions control the actual workflow.

Question: What makes a role map useful?

Model answer: It identifies likely ownership, task types, contact/route information, escalation paths and the next action without inventing authority or provider rules.

Write your own answer first, then compare. Saved in this browser only.

8. Work Boundary

Keep the role map factual and provider-specific.

If a contact, procedure, escalation route or responsibility changes:

CHECK → UPDATE → RECORD THE CHANGE

Do not rely on an outdated map when the provider's current workflow says otherwise.
