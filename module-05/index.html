About this module

Last reviewed: 25 September 2026

Module outcome: Explain the NDIS in plain English, distinguish the roles of key organizations and workplace roles, and recognize when a participant or family question should be referred rather than answered independently.

Practice environment: Wattlebird Support Services — fictional provider, fictional data only.

Practice assets - M5_Situations - M5_Safe_Questions - Provider - Inbox - Source_Verification

Core workflow

DO → CHECK → CLASSIFY → ACT / HAND OFF → FOLLOW UP → CLOSE

Decision layer

  • OK — evidence is sufficient and the VA can proceed within role.
  • FLAG — something needs attention or verification; record and route it.
  • ASK — clarification is required before proceeding.
  • ESCALATE — an authorized person or urgent responsible contact needs to act or decide.

For this module, the key habit is:

Identify the question → identify what is known → check the appropriate source or provider record → stay within role → route the decision → follow up when needed.
