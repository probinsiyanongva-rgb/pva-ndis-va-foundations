Lesson 4.2 — Australian Date and Currency Formats

Practice file: Wattlebird Sandbox Pack v2.3.4 — fictional training data. Work from a copy.Open the Wattlebird practice file

1. Progress Reminder

Time-zone accuracy protects the schedule. Date and format accuracy protects the record.

A document can contain a perfectly typed value that is still dangerous if the convention is misunderstood.

← Module 4 overview

2. Why This Matters

Australian workplace documents commonly use DD/MM/YYYY for dates.

A value such as:

04/11/2026

can be misread by someone using a different convention.

Dates can affect:

  • appointments;
  • invoice periods;
  • deadlines;
  • roster records;
  • service agreements;
  • follow-up dates.

Currency notation can also be important. In this course, Wattlebird uses AUD for fictional Australian-dollar examples.

3. Learn

In Australian format:

  • 04/11/2026 = 4 November 2026
  • 11/04/2026 = 11 April 2026

The M4_Format_Trap sheet contains both examples intentionally.

It also contains:

  • DF-03 — AUD 205
  • DF-04 — 2026-11-03

The point of the exercise is not to reject every format that looks different.

The point is to identify the convention, confirm ambiguous values, and preserve the source evidence.

A useful rule

When a document mixes formats:

  1. identify the source system or document;
  2. check its stated convention;
  3. compare the value with surrounding dates;
  4. check the related record if needed;
  5. record the interpretation or clarification.

Do not "correct" an ambiguous date by guessing.

4. See It

Open:

M4_Format_Trap

Start with DF-01.

04/11/2026

Under Australian DD/MM/YYYY convention, this means:

4 November 2026.

Now compare DF-02:

11/04/2026

Under the same convention, this means:

11 April 2026.

Notice how simply swapping the day and month creates a completely different date.

Which date is 04/11/2026 in Australian format?

Model answer

4 November 2026.

Question

What should you check when a document mixes date formats?

Model answer

Check the document or system's stated convention, compare related records and surrounding dates, and clarify the value when the evidence does not resolve the ambiguity.

8. Work Boundary

You can identify formatting inconsistencies and document what the source shows.

You can correct a clearly established formatting issue in a practice file.

When a date affects a real appointment, invoice, agreement, claim or deadline and the source is ambiguous, ask or escalate rather than inventing the intended date.
