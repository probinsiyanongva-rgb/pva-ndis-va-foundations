About this module

Last reviewed: 25 September 2026

Module outcome: Handle Australian time zones, Philippine–Australian time differences, dates, currency notation, public holidays, availability, and handover accurately.

Practice environment: Wattlebird Support Services — fictional provider, fictional data only.

Practice assets - Roster - Inbox - Provider - M4_Format_Trap - M4_Handover_Template - Source_Verification

Core workflow

DO → CHECK → CLASSIFY → ACT / HAND OFF → FOLLOW UP → CLOSE

For this module, the main reliability habit is:

Identify location → identify date → check the applicable time/date rule → convert or verify → record the result → communicate the next action.

Official reference links
